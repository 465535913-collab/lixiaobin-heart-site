SPECIALTY / CARDIAC SURGERY

心脏外科

重点突出主动脉夹层等复杂主动脉疾病，同时按病种展示常见手术方向与随访重点。

主动脉夹层

重点方向。根据分型、破口位置、脏器灌注及并发症评估开放手术、杂交或腔内治疗策略。

主动脉瘤

关注升主动脉、主动脉弓及胸腹主动脉病变的直径、增长速度与破裂风险。

心脏瓣膜病

二尖瓣、主动脉瓣等瓣膜病变的修复或置换，结合心功能与手术风险制定方案。

冠心病

针对复杂冠状动脉病变评估冠状动脉旁路移植术及围术期二级预防。

成人先天性心脏病

房间隔缺损、室间隔缺损及其他结构异常的手术评估，并关注肺血管阻力与肺高压。

微创与综合治疗

在适合患者中评估小切口、杂交及多学科协作路径，兼顾安全性与恢复质量。

AORTIC DISSECTION

主动脉夹层：为什么需要“抢时间”

主动脉夹层属于可能快速进展的高危主动脉急症。突发剧烈胸背痛、晕厥、神经系统症状、肢体缺血或血压明显异常时，应优先急诊评估，而不是等待普通门诊。
SPECIALTY / PULMONARY HYPERTENSION

肺动脉高压与肺高压

先把“为什么肺动脉压力升高”分清楚，再决定治疗路径。不同病因的治疗策略差异很大。

概念提示：“肺高压（PH）”是总称；“肺动脉高压（PAH）”主要对应肺高压中的第1组。临床上必须先做病因分组，不能把所有肺高压都当成PAH使用靶向药物。

特发性 / 遗传性 PAH

排除左心病、肺部疾病、慢性血栓等原因后，结合右心导管确诊并进行风险分层。

先心病相关 PAH

房缺、室缺、动脉导管未闭等长期分流可引起肺血管重构，是否可关闭缺损需严格评估。

系统性硬化症相关 PAH

硬皮病患者属于高风险人群，需重视呼吸困难、DLCO下降、NT-proBNP及超声异常。

系统性红斑狼疮相关 PAH

需同时评估免疫活动、血栓风险及肺血管病变，治疗常需要风湿免疫与肺高压团队协作。

其他结缔组织病相关

包括混合性结缔组织病等，病程和治疗反应存在异质性，应个体化评估。

慢性血栓栓塞性肺高压

属于肺高压第4组。需要评估肺动脉内膜剥脱术、球囊肺动脉成形术及药物治疗可能性。

左心疾病相关肺高压

常见于瓣膜病、左室收缩或舒张功能异常，治疗核心通常是左心疾病本身。

肺病 / 低氧相关肺高压

COPD、间质性肺病、睡眠低氧等可导致肺高压，需要先处理原发肺病与低氧。

复杂或混合机制

部分患者存在多重机制，需要综合影像、肺功能、实验室、右心导管与多学科判断。

HOME / PATIENT MANAGEMENT

患者管理

分成两条路径：心脏外科围手术期与术后随访，以及肺动脉高压的长期风险管理。

PATH A

心脏外科手术管理

术前评估 → 手术 → ICU / 病房恢复 → 出院 → 复诊 → 长期二级预防。

PATH B

肺动脉高压长期管理

病因分组 → 基线风险评估 → 治疗 → 3–6个月复评 → 目标导向调整。

心脏外科：出院后常见随访点

  • 伤口、体温、胸闷气短与心率血压
  • 血常规、肝肾功能、电解质
  • 心电图、心脏超声；主动脉病变按医嘱复查CTA
  • 抗凝/抗血小板药物及其他心血管用药
  • 逐步恢复活动，避免超负荷运动与自行停药

主动脉夹层术后：重点长期管理

  • 严格血压与心率控制
  • 规律影像随访残余主动脉与人工血管/支架状态
  • 关注新发胸背痛、肢体缺血及神经系统症状
  • 有遗传性主动脉病线索者评估家族筛查

肺动脉高压：复诊常见评估

  • WHO功能分级、症状与晕厥/水肿
  • 6分钟步行试验（6MWD）
  • BNP/NT-proBNP、肝肾功能、电解质
  • 心脏超声与右心功能指标
  • 必要时右心导管、肺功能、CT/VQ等

肺动脉高压：需要尽快联系医生的情况

  • 活动耐量明显下降或出现静息气促
  • 晕厥、胸痛、进行性下肢水肿
  • 体重短期快速增加、尿量明显减少
  • 药物相关低血压、肝功能异常或其他明显不适
具体复诊时间、检查项目和用药调整必须以本人实际病情及主管医生医嘱为准。
HOME / HOW THE HEART WORKS

心脏如何工作

把心脏理解成一个“双泵系统”：右心把缺氧血送去肺，左心把富氧血送往全身。血液永远沿着瓣膜规定的方向前进。

1全身 → 右心
全身回流的缺氧血经上、下腔静脉进入右心房，再通过三尖瓣进入右心室。
2右心 → 肺
右心室收缩，血液经肺动脉瓣进入肺动脉，在肺毛细血管完成气体交换。
3肺 → 左心
富氧血经肺静脉回到左心房，再通过二尖瓣进入左心室。
4左心 → 全身
左心室收缩，血液经主动脉瓣进入主动脉，供应脑、心脏及全身器官。
舒张期心室放松，接受来自心房的血液。
收缩期心室收缩，把血液泵入肺动脉和主动脉。
瓣膜像单向门，防止血液倒流。
冠状动脉给心肌自身供血；狭窄可导致心绞痛或心肌梗死。
